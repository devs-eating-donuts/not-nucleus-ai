# AGENTS.md — Nucleus-AI

Guidance for AI coding agents working in this repo. The authoritative guide is
[`CLAUDE.md`](CLAUDE.md) — **read it first** for the architecture rules, conventions,
and the naming-mode theme. This file exists so tools that read `AGENTS.md` are pointed
there instead of landing with no context.

## Working principle — disagree freely

Push back. When an approach is wrong, weaker than an alternative, or adds needless
complexity / over-engineering, say so directly — with your reasoning and a recommended
alternative — then defer to the maintainer's call and execute it well. Honesty over
agreement; the goal is a genuinely better tool that ships working software.
